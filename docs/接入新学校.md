# 接入新学校

本工具针对**正方教务系统**开发，默认内置广州南方学院的参数。如果你的学校也使用正方教务（URL 形如 `https://jwxt.你的学校.edu.cn/jwglxt/`），大概率只需改一个配置文件就能接入。

> 如果你的学校**不是**正方教务，本工具无法直接使用，需要改核心代码。

## 一、需要知道的参数

学校配置 JSON 支持以下字段（未填的自动沿用内置默认值）：

| 字段 | 含义 | 怎么获取 |
|---|---|---|
| `name` | 学校名（界面显示） | 自己填 |
| `base_url` | 教务系统根地址 | 学校教务网站，形如 `https://jwxt.xx.edu.cn/jwglxt/` |
| `require_layout` | 是否必须带 `layout=default` | 默认 `true`（正方通用），一般不用改 |
| `cookie_is_httponly` | 会话 Cookie 是否 HttpOnly | 默认 `true`，一般不用改 |
| `extra_cookies` | 需要一起带的额外 Cookie 名 | 默认 `["route"]`，一般不用改 |
| `gnmkdm_xk` | **选课功能码** | 见下方「抓包获取」 |
| `gnmkdm_xyqk` | 学业情况功能码 | 见下方「抓包获取」 |
| `jie_time` | 课表节次 → 上下课时间 | 学校作息表 / 见下方 |

其中真正需要「针对你学校」确定的只有 **`base_url`、`gnmkdm_xk`、`gnmkdm_xyqk`、`jie_time`** 四项。

## 二、最简接入（只改 base_url 试试）

很多学校的功能码和南方学院一致（`N253512` / `N551247`），课表作息也接近。**先只改 `base_url` 试跑**，能正常登录、看到课程列表就成功了大半。

1. 复制 `schools/广州南方学院.json` → `schools/我的学校.json`
2. 把 `base_url` 改成你的学校地址
3. 启动：`XK_SCHOOL_PROFILE=schools/我的学校.json python serve.py`
4. 登录，看能否拉出课程列表、教学班、已选

## 三、抓包获取功能码（当最简接入失败时）

功能码 `gnmkdm` 藏在教务系统页面的请求 URL 里。抓包步骤：

1. 用浏览器打开你的教务系统，进入**选课**页面；
2. 按 `F12` 打开开发者工具 → `Network`（网络）标签；
3. 刷新或点「查询」，在请求列表里找 `gnmkdm=` 后面的字符串（形如 `N253512`）；
4. 这就是 `gnmkdm_xk`。

「学业情况统计查询」页面的 `gnmkdm` 同理，通常也在 URL 里（形如 `N551247`）。

> 本项目 `tests/` 目录下有现成的抓包辅助脚本，可参考 `C:/workbuddy/2026-09-28-22-35-06/抓包操作手册.md`（开发环境）。

## 四、课表作息（jie_time）

`jie_time` 是「第 N 节 → 上下课时间」的映射，格式：

```json
"jie_time": {
  "1": "08:00-08:40",
  "2": "08:50-09:30",
  "...": "..."
}
```

从学校的作息时间表抄即可。**注意**：编号要连续（1、2、3…），哪怕中午午休没有课，也要给中间的空节号一个时间（例如南方学院 5 节 12:00 下课、6 节 12:50 才上，中间就是午休）。**表里缺号不等于学校没有那节课**——缺了会导致跨节次的课程在课表上错位。

## 五、高级：接口路径/字段不一致怎么办

如果改了 `base_url` 和功能码后，登录成功但**查不到课程**或**提交报错**，说明你学校的正方教务版本与内置假设不一致（接口路径或提交字段不同）。

这种情况需要对照抓包逐项核对，涉及 `core/config.py` 里的：

- `PATH_XK_INDEX` / `PATH_XK_DISPLAY` 等接口路径
- `QUERY_FIELDS`（45 个查询字段）
- `SUBMIT_FIELDS`（19 个提交字段）
- `DISPLAY_FIELDS` / `CLASS_FIELDS`

这些目前**未开放到 JSON 配置**（它们属于正方教务的版本差异，不是「随学校简单变化」的项）。如果你确认需要，请提交 issue，附上你学校的抓包数据，欢迎一起完善多版本适配。

## 六、常见问题

**Q：登录后一直报「加密串错误」？**
A：`xkkz_xh` 加密串没取到，通常是因为接口路径/页面结构与你学校版本不一致。先确认 `base_url` 正确、功能码正确，再核对接口路径。

**Q：能登录但「已选 0 门」？**
A：可能 `xkly` 等 Tab 级字段与你学校不一致，参考 README 的 issue 通道反馈。

**Q：我想让多个同学用，需要每人装 Python 吗？**
A：不需要。把 exe 发给他们即可，学校配置已内置在 exe 里（或他们用 `XK_SCHOOL_PROFILE` 指向同一份 json）。
