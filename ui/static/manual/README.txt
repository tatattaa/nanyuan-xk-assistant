说明书图片目录（旧版兜底）
================================================================

🔴 2026-10-02 起，界面上「使用说明 → 编辑内容」上传的图片会存到
   **程序目录下的 `manual/img/`**（源码模式 = 项目根 `manual/img/`），
   正文里引用的是 `/manual-asset/文件名`。这个目录是给**旧版 HTML 兜底**用的。

把「使用说明」弹窗里要用的图片放进这个文件夹（png / jpg / gif / svg 都行），
然后在 ui/static/manual.html 里这样引用：

    <img src="/static/manual/你的文件名.png" alt="说明">
    <p class="cap">图 1：说明文字</p>

路径前缀固定是 /static/manual/ —— 只要文件放进本目录，用文件名就能引用。

例：
    本目录放   ui/static/manual/step1.png
    正文里写   <img src="/static/manual/step1.png" alt="第一步">

注意：
  · 图片会自动缩放到弹窗宽度内，等比不拉伸，不用自己改尺寸；
  · 路径写错时页面上会显示「图片没找到 → 路径」，照着改即可；
  · 这个文件只是说明，删掉也不影响功能（但删了空目录可能不会被打包进 exe）。
